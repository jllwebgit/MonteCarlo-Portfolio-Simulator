# モンテカルロ・ポートフォリオ・シミュレーター

複数銘柄（日本の投資信託・ETF等を手入力）の期待リターン・ボラティリティ・コスト・銘柄間相関、
および積立・取崩を入力し、モンテカルロ法で将来の資産評価額の分布をシミュレーションする
金額はすべて**万円単位**で表示します。

セットアップ

pip install -r requirements.txt


起動方法

streamlit run app.py

`http://localhost:8501` が自動的に開きます。`--server.address` 等を指定してのネットワーク公開は想定していません。

## 使い方

1. **サイドバー「設定の保存・読込」**：以前保存したJSONファイルがあれば、ここにアップロードすると
銘柄・相関・積立取崩・初期投資額などをまとめて復元できます（初回は空のままでOK）
2. サイドバーで初期投資額・投資年数・目標金額（すべて万円）・シミュレーション回数などを設定
3. **① 銘柄設定**：「投資金額（万円）」「投資比率（%）」のどちらで入力するかを切り替えられます
（選んだ方の列を編集すると、もう一方の列は自動計算されます）。銘柄名・期待リターン・
ボラティリティ・コストは行ごとに入力（表の下の＋で行追加、行を選んでDeleteで削除）。
「円現預金」は表の下に別枠で表示され、他の銘柄の投資金額合計を初期投資額から差し引いた
残額として自動計算されます（生活防衛資金など、比率ではなく金額で維持する待機資金の想定）。
円現預金の期待リターンのみ、別枠の欄で指定できます
4. **② 銘柄間の相関**：相関係数（-1〜1、円建てリターン基準）を入力
5. **③ 積立・取崩**：積立や取崩しを複数行登録可能。開始年〜終了年の間、毎年その金額（万円）を
加算/減算します
6. **「現在の設定を保存」**：ここまでの設定一式をJSONファイルとしてダウンロードできます。
次回はサイドバーからこのファイルをアップロードすれば、続きから再開できます
7. 「シミュレーション実行」でモンテカルロ法（デフォルト1万回）を計算

## 出力される指標（すべて万円単位）

* **期待リターン**: 各銘柄の（期待リターン − コスト）を投資金額（比率換算）で加重平均した年率値
* **リスク（標準偏差）**: 相関行列を用いて分析的に算出したポートフォリオ全体の年率標準偏差
（√(w^T Σ w)、wは投資比率、Σは共分散行列）
* **シャープレシオ**: （期待リターン − 無リスク金利）÷ リスク。無リスク金利には円現預金の
期待リターンを使用しています
* **シミュレーション平均CAGR**: 積立・取崩が無い場合のみ表示（積立/取崩がある場合、単純CAGRは
意味を持たないため非表示にしています）
* **元本割れ確率**: 最終資産額が「累計投入元本（実際の投資金額合計 + 積立合計 − 取崩合計）」を
下回る割合
* **目標額到達確率**: 最終資産額が目標金額以上になる割合
* **最終資産額の平均値・中央値・最頻値**: シミュレーション結果（万円）の分布特性。最頻値は
ヒストグラム化した際に最も度数の多い区間の中央値を推定値としたものです
* **最大ドローダウン**: 各試行について資産評価額のピークからの最大下落率を算出し、平均・中央値・
悪化5%タイルを表示（積立/取崩による増減も評価額に反映されるため、その影響を含みます）
* **ファンチャート / ヒストグラム**: 資産推移・最終資産額のばらつきを万円単位で可視化

## モデル上の主な前提

* 「目標金額」は目標額到達確率の算出に必須のため入力項目として追加しています。
* 年次ステップのシミュレーションです（月次ではありません）。
* 各銘柄の年次リターンは、指定した期待リターン・ボラティリティ・相関行列に基づく多変量正規分布に
従うと仮定しています。ボラティリティ0（現金など）の銘柄も指定できます。
* コストは各銘柄の期待リターンから毎年差し引く簡易モデルです。
* 「毎年リバランスする」をONにすると毎年末に投資比率（＝各銘柄の投資金額の比率）を目標値へ戻します。
OFFの場合は初期配分のまま各銘柄を複利成長させます（積立は目標比率で追加、取崩しはその時点の
保有比率に応じて按分します）。
* 積立・取崩はその年の運用開始前（年始）に資産評価額へ反映されます。
* 資産評価額は理論上マイナスにならないよう下限0でクリップしています。
* 「① 銘柄設定」で他の銘柄の投資金額合計が初期投資額を超えた場合、円現預金は0となり、
実際の投資金額合計（シミュレーションの起点）は初期投資額を超過した状態で計算されます
（警告が表示されます）。

## 設定の保存・読込（JSONファイル）について

* 「現在の設定を保存」ボタンから、その時点の設定一式をJSONファイルとしてダウンロードできます。
保存される内容は、銘柄設定（投資金額・投資比率・期待リターン・ボラティリティ・コストを含む全銘柄、
円現預金の期待リターン含む）、銘柄間の相関行列、積立・取崩スケジュール、初期投資額・投資年数・
目標金額・シミュレーション回数・リバランス設定・乱数シードです。
* サイドバーの「保存したファイル（JSON）をアップロードして読み込む」に、保存したファイルを
ドラッグ\&ドロップ（またはファイル選択）すると、これらすべてが一括で復元されます。
* 複数のシナリオを比較したい場合は、ファイル名を変えてそれぞれ保存しておくと、
アップロードで簡単に切り替えられます。
* ファイルはブラウザを通じてダウンロードされるだけで、アプリ側では自動保存されません
（明示的に保存・アップロードした場合のみ反映されます）。

## 初期値（デフォルト銘柄・相関）について

起動直後は以下11銘柄が初期値として登録されており、**投資金額はすべて「円現預金」に割り当てられた
状態**（=初期投資額と同額）から始まります。他の銘柄に投資金額（または比率）を入力すると、その分だけ
円現預金が自動的に減少します。

期待リターン・ボラティリティは、長期統計を踏まえた概算値です
（米ドル現預金・円現預金の期待リターンは指定値）。コストは各ファンドの信託報酬の概算値
です。**いずれも将来の成果を保証するものではなく、あくまで初期値（叩き台）です。
実際の投資判断の際は最新の目論見書・運用報告書等でご確認のうえ、ご自身の見立てに合わせて
表内の数値を修正してください。**

相関係数もすべて円建てリターンを基準とした参考値です。特に以下2点にご注意ください。

* **円現預金**: ボラティリティ0のため、相関係数をどう設定しても計算結果には一切影響しません
（円が基準通貨のため、円現預金自体は円に対して変動しない前提です）。
* **米ドル現預金**: 円換算では実質的に為替（USD/JPY）そのものへのエクスポージャーであり、
先進国債券・先進国リート・米国株式など「為替ヘッジなしの外貨建て資産」と、為替変動を通じて
連動します。そのため相関を設定する意味があり、初期値にもあらかじめ入力済みです。
